SECTION 3: RETRAINING FLOW (Continuous Learning)
================================================================================

Trigger Condition (any one of):                     🔲 TODO (Implement in Node.js as cron)
  - New verified ground truth count > 50 (batch threshold)
  - Model accuracy drops below 75% on recent cases
  - Scheduled monthly retraining cycle
  - Manual trigger via Admin Dashboard

   │
   ▼
[FILE] src/train_worker.py  (Tabular Retraining)    ✅ DONE
   │
   │  STEP 1: Connect to PostgreSQL (port 5432 or 5433 Docker fallback)
   │  STEP 2: Run SQL JOINs:
   │
   │    field_reports
   │      LEFT JOIN lab_reports        (confirmed_disease_id  <- PRIORITY 1)
   │      LEFT JOIN vet_verifications  (vet_disease_id        <- PRIORITY 2)
   │
   │  STEP 3: target = lab_confirmed ?? vet_confirmed  (fillna logic)
   │  STEP 4: Encode symptoms with MultiLabelBinarizer
   │  STEP 5: One-hot encode species
   │  STEP 6: Train VotingClassifier (RF + GBM + LR + XGBoost)
   │  STEP 7: Save artifacts to model_registry/
   │
   │  Saves:
   ├──────────────────────────────────────────────────────────►
   │                                           [ML] model_registry/
   │                                                symptom_ensemble_v1.joblib
   │                                                symptom_binarizer.joblib
   │                                                disease_label_encoder.joblib
   │                                                model_columns.joblib
   │
   ▼
[FILE] src/train_image_worker.py  (CNN Retraining)  ✅ DONE
   │
   │  STEP 1: Load images from data/Lumpy Skin Images Dataset/
   │           ├── Lumpy Skin/  (Class 0)
   │           └── Normal Skin/ (Class 1)
   │  STEP 2: Apply transforms (Resize 224x224, Normalize for ImageNet)
   │  STEP 3: Load pretrained ResNet18 (transfer learning from torchvision)
   │  STEP 4: Replace final FC layer for 2 classes
   │  STEP 5: Train for 5 epochs (Adam optimizer, lr=0.001)
   │  STEP 6: Save weights to model_registry/
   │
   │  Saves:
   ├──────────────────────────────────────────────────────────►
   │                                           [ML] model_registry/
   │                                                lumpy_cnn_v1.pth
   │                                                lumpy_class_names.joblib
   │
   ▼
[API] POST /reload-model                            ✅ DONE
[FILE] src/api.py
   │
   │  Calls load_models() internally
   │  Re-reads all .joblib and .pth files from model_registry/ into RAM
   │  Zero-downtime hot-swap: server never restarts!
   │  Called automatically by train_worker.py after saving new files.
