RULES FOR UPDATING TRAINING:
1. Data Accumulation: Trigger retraining when a specific threshold of new ground truth samples (verified by lab reports) is collected.
2. Data Quality: Only incorporate data into the training set if it has been verified by a Lab Report (or high-confidence Vet Diagnosis if lab is unavailable).
3. Performance Drift: Retrain if model confidence or real-world accuracy drops below acceptable thresholds on recent data.
4. Periodic Updates: Run scheduled retraining cycles (e.g., monthly/quarterly) incorporating all new verified data.
